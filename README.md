# web-companies-exercise-server

A small Express + TypeScript server for managing companies. Data is kept in memory, so it is lost whenever the server restarts.

## Data model

The `Company` is the main object. The `id` is generated by the server when a new company is added.

```javascript
{
    id: string;
    name: string;
    address: {
        street: string;
        number: string;
        city: string;
        country: string;
    };
    employees: [
        {
            name: string;
            salary: number;
        }
    ];
}
```

Example request body:

```json
{
    "name": "Acme AG",
    "address": {
        "street": "Bahnhofstrasse",
        "number": "12a",
        "city": "Zürich",
        "country": "Switzerland"
    },
    "employees": [
        { "name": "Anna Muster", "salary": 85000 },
        { "name": "Marco Rossi", "salary": 92000 }
    ]
}
```

## API

| Method | Path             | Body                                   | Response                         |
| ------ | ---------------- | -------------------------------------- |----------------------------------|
| GET    | `/companies`     |                                        | 200, array of companies          |
| GET    | `/companies/:id` |                                        | 200, company / 404               |
| POST   | `/companies`     | `{ "name", "address", "employees" }`   | 201, created company / 400       |
| PUT    | `/companies/:id` | `{ "name", "address", "employees" }`   | 200, updated company / 400 / 404 |
| DELETE | `/companies/:id` |                                        | 204 / 404                        |


## Setup

Prerequisites: [Node.js](https://nodejs.org/) and npm installed.

```sh
git clone <repo-url>
```
```sh
cd web-companies-exercise-server
```
```sh
npm install
```
```sh
npm run dev
```

The server listens on <http://localhost:3000>.
